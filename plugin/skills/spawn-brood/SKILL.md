## Quick Reference

Rules: `GIT-01` (no trunk commits)

Before:
- [ ] `streams`, `fleet_id`, `overlap_risk`, and `overlap_details` inputs are provided
- [ ] tmux is installed
- [ ] claude CLI is available
- [ ] No strain branch already exists locally or remotely

After:
- [ ] Brood manifest written to `.hivemind/fleet/manifest.yaml`
- [ ] All strains spawned as tmux sessions with worktrees
- [ ] Config propagated to each worktree
- [ ] Final action is a Bash tool call (exit 0 = succeeded, exit 1 = blocked)

Dispatch parallel overlord sessions as a brood. Spawns N Claude Code instances in separate git worktrees via tmux, injects task descriptions, and writes the brood manifest.

## Required Inputs

The overlord resolves and passes these. The skill does not resolve them on its own.

- `streams`: array of `{name, description, branch}` — each strain to spawn. This array is the overlord's normalization of cerebrate's canonical `Strains` plan-artifact field (one `streams` element per `Strains` entry).
- `fleet_id`: ISO-8601 timestamp (generated by overlord).
- `overlap_risk`: `low | medium | high` (from planner's overlap assessment).
- `overlap_details`: string (planner's overlap assessment text).

## Procedure

1. **Pre-flight checks.** Run each check; if any fails, emit blocker to stderr and exit 1.
   a. Verify tmux is installed: `command -v tmux`. If missing: `printf 'blocker: tmux is not installed' >&2; exit 1`.
   b. Verify claude CLI is available: `command -v claude`. If missing: `printf 'blocker: claude CLI is not available' >&2; exit 1`.
   c. For each strain, verify the branch does not already exist:
      - Local: `git branch --list <branch>` — if non-empty output: `printf 'blocker: branch %s already exists locally' "<branch>" >&2; exit 1`.
      - Remote: `git ls-remote --heads origin <branch>` — if non-empty output: `printf 'blocker: branch %s already exists on remote' "<branch>" >&2; exit 1`.

2. **Create manifest directory.**
   ```bash
   mkdir -p .hivemind/fleet
   ```

3. **Spawn each strain.** For each strain in `streams`:
   a. Spawn a new Claude Code session in a worktree:
      ```bash
      claude --worktree <branch_name> --tmux
      ```
   b. Discover the tmux session name from `tmux list-sessions` after the spawn command returns. The session name corresponds to the most recently created session associated with the branch.
   c. Wait for session ready — poll with `tmux capture-pane -t <session> -p` checking for a prompt indicator, timeout after 30 seconds. Poll every 2 seconds. If timeout: mark strain as `status: failed`, continue with remaining strains.
   d. Inject task description (escape to prevent shell interpolation):
      ```bash
      escaped_desc=$(printf '%q' "<description>")
      tmux send-keys -t <session_name> "$escaped_desc" Enter
      ```
   e. Record strain data: worktree path (from `git worktree list`), tmux session name, `status: running`.

4. **Config propagation.** If `.claude/settings.local.json` exists in the main checkout, copy it to each successfully spawned worktree's `.claude/` directory:
   ```bash
   cp .claude/settings.local.json <worktree_path>/.claude/settings.local.json
   ```
   Create the `.claude/` directory in the worktree first if it does not exist.

5. **Write brood manifest** to `.hivemind/fleet/manifest.yaml` with this schema:
   ```yaml
   fleet_id: "<fleet_id>"
   coordinator_session: "<current session identifier>"
   overlap_risk: <overlap_risk>
   overlap_details: "<overlap_details>"
   streams:
     - name: "<strain-name>"
       description: "<strain description>"
       worktree_path: "<absolute path to worktree>"
       branch: "<branch name>"
       tmux_session: "<tmux session name>"
       status: running | failed
       pr: null
       merged: false
       rebased_after: []
   merge_order: []
   ```
   Use the exact field names and value types from the Fleet Manifest Schema (v1) in the fleet PRD.

6. **Final Bash tool call.** Emit result and exit:
   - If all strains spawned successfully: emit manifest path on stdout and exit 0.
     ```bash
     printf 'manifest: %s\n' "$(pwd)/.hivemind/fleet/manifest.yaml"; exit 0
     ```
   - If any strains failed: write brood manifest with failed strains marked `status: failed`, emit details on stderr, and exit 1.
     ```bash
     printf 'blocker: %d of %d strains failed to spawn\nmanifest: %s\n' "<failed_count>" "<total_count>" "$(pwd)/.hivemind/fleet/manifest.yaml" >&2; exit 1
     ```

## Failure Modes

| Condition | Action |
|---|---|
| tmux not installed | `printf 'blocker: tmux is not installed' >&2; exit 1` |
| claude CLI not found | `printf 'blocker: claude CLI is not available' >&2; exit 1` |
| Branch already exists (local or remote) | `printf 'blocker: branch <name> already exists' >&2; exit 1` |
| `claude --worktree` command fails | Mark strain `status: failed`, continue with remaining strains, exit 1 at end |
| Session ready timeout (30s) | Mark strain `status: failed`, continue with remaining strains, exit 1 at end |

## Silence Discipline

This is a pipeline skill:

- Produce zero text output at any point during execution. Your only outputs are tool calls.
- Your final action must be a Bash tool call.
- Exit 0 = overlord proceeds. Routing data (if any) is in stdout.
- Exit 1 = blocked. Emit reason: `printf 'blocker: <reason>' >&2; exit 1`
- Never include a `status:` field in any output.

## Do Not

- create branches manually — `claude --worktree` handles branch creation
- commit, push, or open a PR
- modify any product files
- invent values for `streams`, `fleet_id`, `overlap_risk`, or `overlap_details` — exit 1 with blocker if any are missing
- continue when pre-flight checks fail for branch existence
