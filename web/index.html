Claude Code Plugin

Hivemind

Multi-agent orchestration framework for Claude Code. Coordinates specialized bioforms to plan, build, review, and ship code — so you don't have to manage the pipeline yourself.

Install inside Claude Code

/plugin marketplace add https://github.com/brenpike/hivemind.git
/plugin install hivemind@brenpike

The Swarm

Know Your Bioforms

Four specialized agents. Each owns a distinct role in the pipeline. None overlap. Together they close the loop from directive to PR.

👁

Overlord

The control plane. Routes your directives, owns the git lifecycle, distributes work to specialists, and spawns brood sessions. Never writes code. Your main interface.

Orchestrator
🧠

Cerebrate

Originates the plan. Scans the territory and produces the directive — the intelligence the swarm executes. Read-only: thinks, never writes.

Strategist
🔨

Drone

Builds code within its assigned scope. The workhorse of the swarm. Executes implementation phases defined by the cerebrate's directive.

Builder
🎮

Changeling

Handles UI, styling, and visual presentation within assigned scope. Reshapes how things look and feel.

The Pipeline

The Lifecycle

  1. 01 You give the Overlord a task
  2. 02 The Cerebrate scans the territory and returns a directive
  3. 03 The Overlord spawns specialists — Drones and Changelings — phase by phase
  4. 04 Each phase produces essence — knowledge carried forward
  5. 05 An Adaptation Cycle reviews the work before shipping
  6. 06 A PR is opened when the swarm stabilizes 
You
 └─▶ Overlord
      ├─▶ Cerebrate  (plan)
      │    └─▶ Directive
      ├─▶ Drone / Changeling  (build)
      │    └─▶ Essence
      ├─▶ Adaptation Cycle  (review)
      └─▶ PR
Parallel Execution

Brood Mode

When work is big enough, the Overlord splits it into independent strains and dispatches a brood — multiple parallel sessions, each running its own full lifecycle in a separate git worktree.

How it works

  • ◆ Cerebrate decomposes work into independent strains — no shared state between them
  • ◆ Each strain runs its own overlord, cerebrate, drone/changeling pipeline in a tmux session
  • ◆ Each strain lives in its own git worktree and produces its own branch and PR
  • ◆ The Overlord enters hatchery mode — monitoring from home base while strains evolve 
You
 └─▶ Overlord  (hatchery mode)
      └─▶ Cerebrate  (decompose)
           ├─▶ Strain A  ┐
           │    └─▶ own branch, own PR
           ├─▶ Strain B  ├─ parallel
           │    └─▶ own branch, own PR
           └─▶ Strain C  ┘
                └─▶ own branch, own PR
